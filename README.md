# Time Series Sales Forecasting

This project predicts restaurant sales using time-series forecasting and machine learning techniques.

## Project Overview
The notebook analyzes restaurant sales data and forecasts future sales trends.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Time Series Analysis

## Features
- Data cleaning
- Exploratory data analysis
- Sales trend visualization
- Forecasting future sales
- Machine learning models
